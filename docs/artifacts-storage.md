# Artifact Storage

Proof artifacts are optional screenshots, recordings, and diagrams generated by
agent validation. When storage is configured, Hetchy mints presigned upload URLs
and the agent can attach proof links to pull request markdown.

## Disable Artifact Uploads

Leave these values empty:

```dotenv
HETCHY_S3_BUCKET=
HETCHY_S3_REGION=
```

Hetchy will still run agents. Validation prompts ask the agent to report
incomplete proof artifacts instead of uploading files.

## Enable AWS S3

Create an S3 bucket and set:

```dotenv
HETCHY_S3_BUCKET=your-bucket-name
HETCHY_S3_REGION=us-east-1
AWS_ACCESS_KEY_ID=...
AWS_SECRET_ACCESS_KEY=...
AWS_SESSION_TOKEN=
```

The AWS identity needs permission to presign `PutObject` and `GetObject` for the
bucket prefix Hetchy writes into.

## Current Boundary

The current implementation uses the default AWS SDK S3 client with bucket and
region. A custom S3-compatible endpoint, such as MinIO, is not wired through
process config yet. Treat local filesystem storage and MinIO endpoint support as
follow-up work.
