# Slack Setup

Slack is optional. Hetchy supports two Slack paths:

- OAuth install for production/self-hosted deployments with a public HTTPS URL.
- Manual token paste in `HETCHY_ENV=dev`, useful for local development.

## Create A Slack App

1. Open [https://api.slack.com/apps](https://api.slack.com/apps).
2. Create a new app from scratch.
3. Choose the Slack workspace that should contain the bot.
4. Add the bot scopes listed in `internal/bot/slack_oauth.go` or generated by
   `scripts/slack-manifest.template.json`.
5. Subscribe to bot events:
   - `app_mention`
   - `message.im`
6. Enable the App Home messages tab so users can DM the bot.

## OAuth Install Path

Set a public base URL and Slack app credentials:

```dotenv
HETCHY_PUBLIC_BASE_URL=https://hetchy.example.com
SLACK_CLIENT_ID=...
SLACK_CLIENT_SECRET=...
SLACK_SIGNING_SECRET=...
SLACK_OAUTH_REDIRECT_URI=https://hetchy.example.com/slack/oauth/callback
```

Configure Slack with:

```text
Event request URL: https://hetchy.example.com/slack/events
Interactivity request URL: https://hetchy.example.com/slack/interactivity
OAuth redirect URL: https://hetchy.example.com/slack/oauth/callback
```

After restarting Hetchy, sign in as an organization admin and open
**Organization settings -> Integrations -> Slack**. Click **Enable** to install
the Slack app into that workspace.

## Dev Manual Token Path

In `HETCHY_ENV=dev`, admins can paste tokens directly into the Slack integration
card. This path uses Socket Mode and does not require a public callback URL.

Create:

- A bot token from **OAuth & Permissions**. It starts with `xoxb-`.
- An app-level Socket Mode token with `connections:write`. It starts with
  `xapp-`.

Paste both tokens in **Organization settings -> Integrations -> Slack**.

## Verify

1. Invite the bot to a channel: `/invite @YourBotName`.
2. Mention the bot in that channel or DM it directly.
3. Confirm Hetchy posts a threaded "Working on it" response and links back to
   the web conversation.

## Common Issues

**Slack card says the environment is not configured**

Set `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET`, `SLACK_SIGNING_SECRET`, and
`SLACK_OAUTH_REDIRECT_URI`, then restart Hetchy. In `HETCHY_ENV=dev`, use the
manual token path instead.

**Invalid auth or socket connection failures**

Check for extra spaces in the `xoxb-` and `xapp-` tokens, confirm Socket Mode is
enabled, and reinstall the app after changing scopes.

**Bot does not respond**

Verify `app_mention` and `message.im` event subscriptions, invite the bot to the
channel, and check server logs for Slack signature or team lookup failures.
